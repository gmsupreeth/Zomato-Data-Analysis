Zomato Data Analysis

  Project Overview
This project analyzes Zomato restaurant data to identify trends, patterns, and insights related to restaurants, ratings, cuisines, and locations.

   Tools Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization

   Project Objectives
- Clean and prepare the Zomato dataset
- Analyze restaurant data
- Identify trends and patterns
- Create meaningful visualizations
- Generate useful insights
